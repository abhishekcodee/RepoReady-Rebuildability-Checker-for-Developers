# RepoReady-Rebuildability-Checker-for-Developers

RepoReady: An Open-Source Project Rebuildability and Configuration Checker

RepoReady is a local developer tool that will inspect software project
directories for common rebuildability and reproducibility problems. It is
designed to work offline, avoid executing inspected project code, and provide
clear findings for developers who need to share or rebuild a project.

## Current status

This repository currently contains **Stage 3: CLI integration**. The package
metadata, pinned Python runtime, safe static project scanner, eight structured
rebuildability checks, weighted scoring, terminal reporting, and sanitized JSON
report generation are configured. RepoReady works offline and does not execute
inspected project code.

## Requirements

- Python 3.12.7
- [uv](https://docs.astral.sh/uv/) for environment and lockfile management
- Git for version control
- Docker for the later containerized workflow

RepoReady itself is intended to use only the Python standard library at
runtime.

## Development setup

From the repository root:

```bash
uv sync --locked
```

The project pins the compatible Python line in `.python-version` and the
package metadata requires Python 3.12.7 or a later Python 3.12 patch release.
The committed `uv.lock` file is generated by `uv`. The `--locked` flag keeps
setup reproducible and fails if `pyproject.toml` and `uv.lock` diverge.

## Current command-line entry point

After synchronizing the environment:

```bash
uv run repoready --help
uv run repoready --version
uv run repoready PATH
uv run repoready PATH --json report.json
uv run repoready PATH --verbose
```

`PATH` must be an existing project directory. A scan prints the score, coverage,
all eight check results, recommendations, and limitations. `--json` writes the
same sanitized report to the requested existing output directory; it does not
create parent directories. `--verbose` includes scanner error details in the
limitations section. The scan is static: project code, setup scripts, tests,
and network calls are not executed.

RepoReady uses these exit codes:

- `0`: scan and report succeeded, including when findings are present.
- `1`: operational failure, including a JSON export failure.
- `2`: invalid command-line input or scan target.

## Tests

The project uses Python's standard-library `unittest` framework. With the
development environment active, run:

```bash
python -m unittest discover -s tests -v
```

The tests are designed to run offline.

## Project structure

```text
src/repoready/   Python package, scanner, checks, and CLI entry point
tests/            Offline automated tests
pyproject.toml    Package metadata and tool configuration
.python-version   Pinned Python runtime line
uv.lock          uv-generated dependency lockfile
```

No environment variables are currently required by RepoReady itself, so an
`.env.example` file is not included.
