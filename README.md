# RepoReady

RepoReady is a local developer tool that will inspect software project
directories for common rebuildability and reproducibility problems. It is
designed to work offline, avoid executing inspected project code, and provide
clear findings for developers who need to share or rebuild a project.

## Current status

This repository currently contains **Stage 2: Core Scanner and Rebuildability
Checks**. The package metadata, pinned Python runtime, command-line entry
point, safe static project scanner, eight structured rebuildability checks, and
offline tests are configured. Scoring, terminal reporting, and JSON report
generation are intentionally deferred to later stages.

## Requirements

- Python 3.12.7
- [uv](https://docs.astral.sh/uv/) for environment and lockfile management
- Git for version control
- Docker for the later containerized workflow

RepoReady itself is intended to use only the Python standard library at
runtime.

## Development setup

From the repository root:

```bash
uv sync --locked
```

The project pins the compatible Python line in `.python-version` and the
package metadata requires Python 3.12.7 or a later Python 3.12 patch release.
The committed `uv.lock` file is generated by `uv`. The `--locked` flag keeps
setup reproducible and fails if `pyproject.toml` and `uv.lock` diverge.

## Current command-line entry point

After synchronizing the environment:

```bash
uv run repoready --help
uv run repoready --version
```

Passing a project path currently returns an explanatory Stage 1 message. The
scanner will be added in Stage 2.

## Tests

The project uses Python's standard-library `unittest` framework. With the
development environment active, run:

```bash
python -m unittest discover -s tests -v
```

The tests are designed to run offline.

## Project structure

```text
src/repoready/   Python package, scanner, checks, and CLI entry point
tests/            Offline automated tests
pyproject.toml    Package metadata and tool configuration
.python-version   Pinned Python runtime line
uv.lock          uv-generated dependency lockfile
```

Scoring, report generation, examples, Dockerfile, CI configuration, and
complete user documentation will be added in the approved later stages. No
environment variables are currently required by RepoReady itself, so an
`.env.example` file is not included.
